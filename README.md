# 美容予約アプリ

美容院の予約を管理できるシンプルなWebアプリです。
予約の追加・編集・削除、一覧表示、今日の予約表示などの機能を実装しています。

## 主な機能

‐ 予約の追加・編集・削除
‐ 名前によるキーワード検索
‐ 今日・未来・過去の予約を分けての表示
‐ メニューと担当者の選択
‐ カレンダー表示
‐ 前月・翌月への移動
‐ 1月・12月の年またぎ対応
‐ 今日の日付のハイライト表示
‐ 予約がある日にドットを表示
‐ カレンダーの日付クリックで予約内容を確認
‐ カレンダーからの予約の編集・削除
‐ 総売上の表示
‐ メニュー別予約件数
‐ スタッフ別予約件数・売上
‐ 月別売上の表示
‐ 月別売上の棒グラフ
‐ スマホ表示に対応

## 工夫した点

‐ 今日・未来・過去の予約分けて表示し、必要な予約を確認しやすくしました。
‐ カレンダーから予約のある日を確認し、日付をクリックすると予約内容を表示できるようにしました。
‐ 今日の日付のハイライト、予約日のドット表示、前月・翌月への移動を実装しました。
‐ 予約内容の確認画面から、そのまま編集・削除できるようにしました。
‐ 総売上、メニュー別件数、スタッフ別件数・売上、月別売上を集計しました。
‐ 月別売上は棒グラフでも確認できるようにしました。
‐ 美容院らしい大人可愛いデザインと、見やすい余白・配色を意識しました。
‐ パソコンとスマートフォンの両方で見やすいように調整しました。
